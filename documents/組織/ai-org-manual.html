※ AI 組織の脳（CLAUDE/AGENTS/DOCS）の反映は make push（git: keyaki-org-workdir）に一本化。旧 make deploy-agent は廃止。

ワークディレクトリ同期（git）

make pullサーバーの最新を git pull で取り込む（作業前に必ず）
make push自動コミット → git push → サーバーで git pull まで実行（脳の反映もこれ）
make pull-dry / push-dry未取得コミット / 未コミット変更のプレビュー

repo: keyaki-dev/keyaki-org-workdir（サーバー ~ を private 管理）
ローカル clone: ~/Documents/repos/keyaki/keyaki-org-workdir/

サーバーは cron 毎時で自動 commit+push。同一行が衝突したら自動解決せず ~/org-autocommit.log に記録 → 手動解決。

※ 同期は git に一本化済み。旧 rsync ミラー（server-share/・scripts/sync.sh）は廃止した。

Initial Setup

初回セットアップ

1

VM 上でセットアップスクリプトを実行

bash scripts/setup.sh — claude CLI・gh・gcloud・gws、および GPU ドライバ・Ollama・opencode を導入。各ロールのディレクトリ（orchestrator/ pm-focusburst/ … accounting/）を初期化。

2

Claude・GitHub・GCP を認証する

claude auth login でサブスク認証。gh auth login で keyaki-dev アカウントを登録（reatex 用に rtx-yamashita も登録）。

3

佐藤（accounting）のローカル LLM を用意する

Ollama に gemma 系モデルを pull し、num_ctx 拡張派生（gemma4-sato）を生成。佐藤は claude ではなく opencode → Ollama で駆動する。

4

AI組織の脳と skills を反映する（ローカルから）

make push — 脳（CLAUDE/AGENTS/DOCS・org.md・_shared）を git（keyaki-org-workdir）でサーバーへ反映。make deploy で skills を ~/.claude/skills/ へ転送。

5

orchestrator に接続して動作確認

make cli — tmux: orchestrator に接続。org.md / DOCS.md を読んで全体の文脈を把握し待機状態になれば完了。

Roadmap

自律化ロードマップ

1

Phase 1 — プロジェクト縦割り・PM 制 現在
