# edanet X 続報投稿 下書き（Sprint7 A-4）

A-3 ティザー投稿（7/17 自動投稿）の反応を受けて使用する続報パターン。
投稿タイミングは orchestrator が判断する。

---

## Pattern 1 — β 招待型

**ターゲット**: ティザー投稿を見て興味を持ったユーザー / フォロワー
**目的**: β テスト参加者の獲得・/beta ページへの誘導

```
edanet、βテスト参加者を募集しています。

AIで作ったコード・プロンプト・文章をシェアして、誰かがフォークする場所。

使ってみたい方、フィードバックをくれる方はこちらから↓
https://edanet.keyaki-dev.com/beta
#edanet #AI創作 #フォーク文化
```

**文字数**: 約 129 字（URL は 23 字換算）

---

## Pattern 2 — 機能紹介型

**ターゲット**: 「フォーク」という概念が気になっているユーザー
**目的**: コア機能（フォーク + 系譜ツリー）をシンプルに伝える

```
edanet のフォーク機能：

誰かのプロンプトを「フォーク」して自分流に改造できる。
改造作品は元ネタと「系譜ツリー」で繋がる。

アイデアの進化が可視化される場所。

https://edanet.keyaki-dev.com
#edanet #AI創作 #フォーク文化
```

**文字数**: 約 127 字（URL は 23 字換算）

---

## Pattern 3 — ユーザーストーリー型

**ターゲット**: 「自分がどう使えるか」イメージしたいユーザー
**目的**: 具体的な活用シーンを見せてアクション意欲を引き出す

```
こんな場面を想像しています。

プロンプトを誰かが投稿
→ デザイナーがフォークしてアニメ風に改造
→ 小説家がさらにフォークして情景描写に応用

1つのアイデアが、家系図になる。

https://edanet.keyaki-dev.com
#edanet #AI創作 #フォーク文化
```

**文字数**: 約 134 字（URL は 23 字換算）

## 投稿ガイドライン

- A-3（7/17 投稿）への反応数・リプライ内容を見てから orchestrator が投稿パターン・タイミングを選択
- Pattern 1（β招待型）は /beta ページ公開確認後に使用
- 3パターン連投は NG。1投稿選んで単体で使う
- 反応が良ければ Pattern 2 → Pattern 3 の順で数日おきに投稿するのが自然な流れ
