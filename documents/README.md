# keyaki チームポータルへようこそ

このポータルはチームの資料・仕様書・議事録を一元管理するための場所です。

## ディレクトリ構成

| ディレクトリ | 用途 |
|---|---|
| `proposals/` | 提案資料 |
| `specs/` | 仕様書 |

## ドキュメントの追加方法

`documents/` ディレクトリ配下に `.md` または `.html` ファイルを追加するだけで自動的に一覧に表示されます。

### Markdown ファイル

ファイル先頭にフロントマターで `title` を指定すると、そのタイトルが一覧に表示されます。

```
---
title: ドキュメントのタイトル
---

# 本文...
```

### HTML ファイル

通常の HTML ファイルをそのまま配置できます。iframe で表示されます。
