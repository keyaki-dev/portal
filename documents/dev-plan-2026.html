4Forkbox 詳細計画

MVP スコープ（7月末 α リリース対象）

バックエンド基盤（田中 W1〜W2）

田中（BE）/ 川上（技術選定）
技術スタック（W1 確定）
  • DB + Auth: Supabase（Row Level Security + Auth で認証と DB を統合）または Firebase
  • API: Next.js API Routes（既存 FE と同リポジトリ）
  • ORM: Prisma or Supabase Client
  • ホスティング: Vercel（FE） + Supabase Cloud（BE）
DBスキーマ（主要テーブル）
  • users: id / name / avatar / bio / created_at
  • posts: id / user_id / type（url/code/idea）/ content / created_at
  • likes: id / user_id / post_id / created_at
  • forks: id / user_id / source_post_id / post_id
  • follows: follower_id / followee_id

認証（田中 + 中村 W2）

田中（API） / 中村（FE）
実装内容
  • Google OAuth 2.0 ログイン
  • セッション管理（JWT or Supabase Auth）
  • ログイン・ログアウト・未認証リダイレクト
  • 初回ログイン時のプロフィール作成フロー
完了条件
  • Google アカウントでログインしてフィードが表示されること
  • 未ログイン状態で投稿しようとするとログイン画面へ遷移すること

投稿・フィード・基本インタラクション（田中 + 中村 W2〜W3）

田中（API） / 中村（FE）
MVP 機能
  • 投稿: URL / コード / アイデア の3種類。タイトル + 内容 + タグ
  • フォーク: 他人の投稿を自分流に派生させる（source_post_id 紐付け）
  • フィード: フォロー中のユーザーの投稿 + 全体タイムライン
  • いいね: トグル式。カウント表示
  • プロフィール: 投稿一覧・フォロー/フォロワー数表示・アバター変更
v2 以降（スコープ外）
  • 系譜ビュー（フォーク ツリー表示）
  • コレクション（ブックマーク機能）
  • 通知（いいね・フォーク・フォロー）
  • コメント機能
  • 検索・タグ絞り込み
