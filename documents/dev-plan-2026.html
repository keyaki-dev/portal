1組織目標と戦略概要

組織目標: 2026年12月までに売上累計 100万円 を達成する

売上戦略の順序

  1. FocusBurst（第1弾） で組織・マーケのサイクルを確立する。収益化実装→ユーザー獲得→次フェーズの順で積み上げる
  2. Forkbox を正式リリースして第2の収益柱を立てる。2026年Q4での正式リリースを目指す
  3. 上記2本のプロダクト実績を引っ提げて、Startup Scaffold のコンサル外部展開を開始する

2FocusBurst ロードマップ

現状サマリー
  • URL: focusburst.keyaki-dev.com（PWA 公開済み）
  • 機能: ポモドーロタイマー（5/10/15分）、フリーミアム（1日3回制限）
  • マーケ: X自動投稿 週4本稼働中 / note記事 週5本体制構築中
  • 収益化: 課金UI は「準備中」のまま温存中

Phase A — 収益化実装

2026年7月〜8月 川上（実装）

フリーミアムの収益化を実装し、初回の有料ユーザーを獲得する。

実装タスク
  • 月額サブスクリプション（300〜500円/月）プラン設計
  • Stripe（またはLemonSqueezy）決済統合
  • プレミアム機能の実装（無制限利用 / セッション統計 / カスタムタイマー）
  • ユーザー認証（NextAuth / Clerk）とアカウント管理画面
  • 課金UIの「準備中」から正式リリースへの切り替え
KPI（Phase A完了条件）
  • 有料プランのリリース完了
  • 初回有料ユーザー 10人獲得
  • 月次MRR: 3,000円〜5,000円
  • 決済エラー率 1%未満

Phase B — ユーザー獲得

2026年7月〜9月 石川（マーケ）

SNSマーケ・SEO・アプリストア展開でユーザーベースを拡大する。

施策
  • X: 週4本投稿の継続・使用感レポート系コンテンツ強化
  • note: ADHD・集中術関連 SEO 記事の継続執筆（週5本）
  • PWA → iOS/Android アプリストア公開の検討（川上）
  • Product Hunt 掲載（英語圏への展開足がかり）
  • ADHD コミュニティ（X・Reddit）へのアウトリーチ
KPI（Phase B目標）
  • 月間アクティブユーザー（MAU）: 1,000人
  • 有料転換率: 2〜5%
  • 有料ユーザー累計: 50人
  • 月次MRR: 15,000〜25,000円
  • note記事 累計20本公開

Phase C — 機能拡張

2026年9月〜12月 川上（実装）/ 石川（GTM）

コアユーザーのフィードバックをもとに差別化機能を追加し、解約率低下・LTV向上を図る。

機能候補
  • AIボディダブリング: 音声・映像で「一緒に作業する仲間」を演出するAI機能
  • セッション記録・週次レポート（グラフ表示）
  • カスタムBGM / 集中音（ホワイトノイズ等）
  • Slackインテグレーション（集中モード通知）
  • チーム機能（複数人で一緒に集中）
KPI（Phase C目標）
  • 有料ユーザー累計: 150人
  • 月次MRR: 50,000〜75,000円
  • 月次解約率: 5%以下
  • App Store / Play Store 評価: 4.0以上
  • FocusBurst 累計売上貢献: 30〜40万円

Phase 5 — 設計固め

2026年6月 千葉（PM）/ 川上（レビュー）

川上レビューの指摘を要件定義に反映し、バックエンド実装前にアーキテクチャを確定する。

タスク
  • 川上レビュー結果の要件定義書への反映
  • フォーク体験フロー（UX）の確定
  • DB スキーマ設計（ユーザー / フォーク / コメント等）
  • API エンドポイント設計書の作成
  • 技術スタック確定（Next.js + Supabase / PlanetScale 等）
完了条件
  • 要件定義書 v2 の山下承認
  • API 設計書の川上レビュー通過
  • Phase 6 着手判断が可能な状態

Phase 6 — バックエンド実装

2026年7月〜8月 川上（実装）

設計書をもとにバックエンドを構築し、フロントエンドモックと接続する。

実装スコープ
  • 認証基盤（Clerk / NextAuth）
  • DB セットアップ・マイグレーション
  • コア API（フォーク作成・一覧・詳細・削除）
  • ユーザープロフィール API
  • フロントエンドとの API 結合
  • CI/CD パイプライン整備（GitHub Actions + Vercel）
KPI（Phase 6完了条件）
  • 主要 API のユニットテスト通過
  • 開発環境でエンドツーエンド動作確認
  • Vercel Preview デプロイで川上・山下確認済み

Phase 7 — アルファ版リリース

2026年8月〜9月 川上（実装）/ 山口（デザイン）

クローズドな限定ユーザーにアルファ版を公開し、コアUXの検証を行う。

タスク
  • 本番環境へのデプロイ（Vercel + 独自ドメイン）
  • 山口によるデザイン QA・ポリッシュ
  • アルファテスター 10〜20人の招集（山下ネットワーク活用）
  • フィードバック収集フォームの設置
  • クリティカルバグ修正サイクルの確立
KPI（Phase 7完了条件）
  • アルファテスター 15人以上が実際に使用
  • NPS（推奨度）スコア: 30以上
  • 重大バグ（P0/P1）ゼロの状態でベータ移行判断

Phase 8 — ベータ版・マーケティング開始

2026年10月 石川（GTM）/ 山口（デザイン）/ 川上

公開ベータとして一般ユーザーに開放し、マーケティングを本格始動する。

タスク
  • ランディングページ完成（山口デザイン）
  • X / note でのティザー・ローンチ発信（石川）
  • ウェイトリスト解放 → ベータ開放
  • 収益化モデルの最終確定（月額 / 従量 / フリーミアム）
  • アクセス解析（Vercel Analytics / Mixpanel）導入
KPI（Phase 8完了条件）
  • ベータ登録者: 200人
  • 週間アクティブユーザー（WAU）: 100人
  • X フォロワー（Forkbox 専用アカウント想定）: 500人

Phase 9 — 正式リリース

2026年11月〜12月 全員

課金システムを稼働させ正式リリース。2026年Q4の売上柱として確立する。

タスク
  • Stripe 決済統合・プレミアムプランのリリース
  • 利用規約・プライバシーポリシーの整備
  • 正式ローンチ発信（X / note / Product Hunt）
  • カスタマーサポート体制の整備
  • Startup Scaffold の実績紹介コンテンツとしての活用
KPI（リリース時目標）
  • 正式リリース当月の新規有料ユーザー: 30人
  • 月次MRR: 30,000〜50,000円
  • Forkbox 累計売上貢献: 30〜60万円
  • MAU: 500人
