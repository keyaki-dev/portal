# 経理管理

keyaki の経理は外部 SaaS を使わず、このサーバー上で完結させる（That's Source 方針）。

---

## 基本方針

- **データ保管場所**: `~/keyaki/accounting/` ディレクトリ（サーバー上）
- **将来の DB**: PostgreSQL をサーバーに立てて構造化データを管理（現時点は未構築）
- **担当**: 川上が自律的に管理・記録・レポート作成を行う

---

## ディレクトリ構成

```
~/keyaki/accounting/
├── receipts/          # 領収書・請求書の原本
│   └── YYYY/
│       └── MM/
│           ├── YYYYMMDD_NNN_説明.jpg    # 画像ファイル
│           └── YYYYMMDD_NNN_説明.json  # OCR結果・メタデータ
├── reports/           # 月次・年次レポート
│   └── YYYY/
│       └── YYYY-MM_monthly.md
└── exports/           # 確定申告用エクスポート
    └── YYYY_all.csv
```

## 将来の DB スキーマ（計画）

PostgreSQL を導入した際は以下のスキーマで管理する。

```sql
-- 勘定科目マスタ
CREATE TABLE accounts (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,   -- 売上、通信費、外注費 など
  type VARCHAR(10) NOT NULL     -- 'income' or 'expense'
);

-- 取引明細
CREATE TABLE transactions (
  id SERIAL PRIMARY KEY,
  date DATE NOT NULL,
  account_id INTEGER REFERENCES accounts(id),
  amount INTEGER NOT NULL,      -- 税抜き金額（円）
  tax_rate NUMERIC(4,2),        -- 0.10 または 0.08（軽減税率）
  description TEXT,
  receipt_path TEXT,            -- receipts/ 以下の相対パス
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 主な勘定科目（個人事業主）

| カテゴリ | 具体例 |
|---|---|
| 売上 | Scaffold 案件受注、アプリ収益（Focus Burst 等） |
| 通信費 | サーバー代（GCE）、ドメイン費用 |
| 外注費 | 業務委託費 |
| 消耗品費 | 機器・備品の購入 |
| 研修費 | 書籍・学習サービス |
| 諸会費 | ソフトウェアサブスク（必要最小限） |

## 運用フロー（現時点）

収入・支出が発生したら、山下が川上に Slack で連絡する。川上がファイルへの記録と管理を担当する。DB・Slack 自動化は取引量が増えてから導入する。
