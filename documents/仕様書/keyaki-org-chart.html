Members

役割分担

窓口

orchestrator（千葉）

  • 山下の唯一の窓口・Slack 報告
  • 各 PM へのタスク振分
  • 実装・詳細把握はしない
PM

pm-focusburst / pm-forkbox

  • 各プロダクトの進捗を所有
  • DOCS.md を常に最新化（最重要）
  • 実装プールへタスクを分解・投函
実装・専門プール

engineer / frontend / backend / designer / marketing

  • PM の指示で実装・制作（指示待ち徹底）
  • PR は発行のみ・マージは山下
  • reviewer が PR をコメントレビュー
オンデマンド： legal（法務）/ accounting（経理・ローカルLLM）は常駐せず、必要時に kick で起動。Slack 発言は orchestrator のみ。
